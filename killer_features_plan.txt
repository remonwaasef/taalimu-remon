### 🏆 المستوى الأول: "لماذا لم يكن هذا موجوداً من قبل؟!" (أعلى تأثير)

#### 1. 📱 بوابة ولي الأمر (Parent Portal)
> لماذا قاتلة؟ 90% من قرار التسجيل في المركز يأخذه ولي الأمر، وليس الطالب.

ما يراه ولي الأمر:
- 📊 متابعة لحظية لحضور وغياب ابنه
- 📝 درجات الاختبارات والتقييمات أولاً بأول
- 💰 حالة المدفوعات والأقساط المتبقية
- 📅 جدول حصص ابنه الأسبوعي
- 💬 محادثة مباشرة مع المعلم
- 🔔 إشعارات فورية (تأخر، غياب، درجة جديدة)
- 📈 تقرير شهري تلقائي عن مستوى الابن

التأثير التجاري: العميل الذي يفعّل هذه الميزة لن يستطيع إلغاء اشتراكه أبداً لأن أولياء الأمور سيطالبون باستمرارها.

| الصعوبة | المدة المقدرة | الأولوية |
|---------|--------------|----------|
| 🟡 متوسطة | 2-3 أسابيع | 🔴 فورية |

#### 2. 📲 إشعارات واتساب التلقائية (WhatsApp Auto-Notifications)
> لماذا قاتلة؟ الواتساب هو التطبيق #1 في السعودية والشرق الأوسط. البريد الإلكتروني لا يقرأه أحد.

الإشعارات التلقائية:
- ✅ "ابنك أحمد حضر اليوم الساعة 4:30" (فوري عند تسجيل الحضور)
- ⚠️ "ابنك أحمد لم يحضر حصة الرياضيات اليوم"
- 💰 "تذكير: قسط شهر يونيو بقيمة 500 ر.س مستحق بعد 3 أيام"
- 📊 "تقرير أحمد الأسبوعي: حضر 4/5 حصص، درجة الاختبار 85%"
- 🎉 "مبروك! أحمد حصل على المركز الأول في اختبار القرآن"
- 📅 "تذكير: غداً حصة إضافية الساعة 5 مساءً"

التأثير التجاري: هذه الميزة وحدها تبرر رفع سعر الباقة 200 ر.س شهرياً.

#### 3. 💳 الدفع الإلكتروني المتكامل (Online Payment Gateway)
> لماذا قاتلة؟ المركز الذي يحصّل إلكترونياً يحصّل أسرع بنسبة 60% ويقل تأخر الأقساط 80%.

المميزات:
- 💳 دفع بالبطاقة البنكية (Visa/Mastercard/mada)
- 🏦 تحويل بنكي مع تأكيد تلقائي
- 📱 Apple Pay / STC Pay
- 🔄 أقساط تلقائية شهرية (Auto-debit)
- 🧾 فاتورة إلكترونية متوافقة مع هيئة الزكاة (ZATCA)
- 🔗 رابط دفع يُرسل للعميل عبر واتساب

التكامل المقترح: Moyasar أو Tap Payments (الأسهل في السعودية)

### الميزة 1: 📲 إشعارات واتساب التلقائية المتقدمة
**المدة:** 2-3 أيام | **الصعوبة:** 🟢 سهلة (البنية جاهزة)

#### ما هو موجود حالياً:
- `WhatsAppService` يرسل إشعارات الحضور والدفع فقط
- لا توجد إشعارات غياب أو تذكيرات أقساط أو تقارير أسبوعية

#### المطلوب إضافته:

**ملف: `app/Services/WhatsAppService.php`** — إضافة Methods جديدة:

```php
// 1. إشعار الغياب
sendAbsenceNotification($tenant, $student, $course, $date)
// "⚠️ تنبيه: ابنك أحمد لم يحضر حصة الرياضيات اليوم الأحد 19/5"

// 2. تذكير القسط
sendInstallmentReminder($tenant, $student, $amount, $dueDate)  
// "💰 تذكير: قسط شهر يونيو بقيمة 500 ر.س مستحق بعد 3 أيام"

// 3. تقرير أسبوعي
sendWeeklyReport($tenant, $student, $attendanceRate, $quizAvg)
// "📊 تقرير أحمد الأسبوعي: حضر 4/5 حصص، متوسط الدرجات 85%"

// 4. إشعار درجة جديدة
sendGradeNotification($tenant, $student, $quiz, $score)
// "📝 أحمد حصل على 90% في اختبار القرآن الكريم"

// 5. إشعار ترحيب
sendWelcomeMessage($tenant, $student)
// "🎉 أهلاً بـ أحمد في مركز النور! نتمنى له رحلة تعليمية ممتعة"
```

**ملف جديد: `app/Console/Commands/SendPaymentReminders.php`** — أمر مجدول:

```php
// يعمل يومياً الساعة 9 صباحاً
// يبحث عن طلاب لديهم أقساط مستحقة خلال 3 أيام
// يرسل تذكير واتساب تلقائي
```

**ملف جديد: `app/Console/Commands/SendWeeklyReports.php`** — أمر مجدول:

```php
// يعمل كل جمعة الساعة 10 صباحاً  
// يحسب نسبة الحضور ومتوسط الدرجات لكل طالب
// يرسل تقرير مختصر لولي الأمر عبر واتساب
```

**تعديل: `app/Console/Kernel.php`:**
```php
$schedule->command('reminders:payment')->dailyAt('09:00');
$schedule->command('reports:weekly')->weeklyOn(5, '10:00'); // الجمعة
```

**تعديل: `AttendanceController@store`** — إضافة سطر بعد تسجيل الغياب:
```php

    app(WhatsAppService::class)->sendAbsenceNotification($tenant, $student, $course, now());

```
