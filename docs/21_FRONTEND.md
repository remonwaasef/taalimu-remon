# 21_FRONTEND - Frontend Architecture & Vite

- **Blade + Alpine.js**: Server-rendered marketing pages and basic forms.
- **Inertia.js React 19**: Interactive SPA dashboard views without building decoupled APIs.
- **TailwindCSS 3.4 & Bootstrap 5.3**: Utility styling combined with Bootstrap modal/table components.
- **Brand Identity & Design Tokens (v1.0)**: Centralized design system in `resources/css/design-tokens.css` with Taalimu Indigo (`#5B5FEF`), Snow background (`#F8FAFC`), 10px/16px/20px radius scale, and Cairo/Inter typography.
- **Vite Asset Bundler**: Modern HMR build tool (`vite.config.js` and `vite-module-loader.js`).
