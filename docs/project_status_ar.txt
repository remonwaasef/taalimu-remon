🎯 ماهو المشروع؟
================================================================================

هذا المشروع هو نظام SaaS متكامل لإدارة المراكز التعليمية مبني بتقنية Laravel 12.
النظام يسمح للمراكز التعليمية المختلفة بالاشتراك واستخدامه لإدارة عملياتهم 
التعليمية بشكل كامل.

النموذج التقني:
-----------------
• Multi-Tenancy System: نظام متعدد المستأجرين حيث كل مركز تعليمي له بياناته المعزولة
• Shared Database with Tenant ID: قاعدة بيانات مشتركة مع عزل البيانات عن طريق tenant_id

حزمة التقنيات (محدثة):
-----------------
• Backend: Laravel 12 (PHP 8.4)
• Frontend: Blade + Tailwind CSS + Alpine.js (تحديث من Bootstrap)
• Database: MySQL 8.0 / MariaDB
• JavaScript: Alpine.js + Vite
• Modules: nwidart/laravel-modules (6 وحدات نشطة)
• Permissions: spatie/laravel-permission (RBAC كامل)
• Activity Log: spatie/laravel-activitylog (Audit Trail)
• Payments: Laravel Cashier (Stripe) + PayPal + Paymob
• Real-time: Laravel Reverb (WebSockets)
