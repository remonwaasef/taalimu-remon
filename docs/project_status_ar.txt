🎯 ماهو المشروع؟
================================================================================

هذا المشروع هو نظام SaaS متكامل لإدارة المراكز التعليمية مبني بتقنية Laravel.
النظام يسمح للمراكز التعليمية المختلفة بالاشتراك واستخدامه لإدارة عملياتهم 
التعليمية بشكل كامل.

النموذج التقني:
-----------------
• Multi-Tenancy System: نظام متعدد المستأجرين حيث كل مركز تعليمي له بياناته المعزولة
• Shared Database with Tenant ID: قاعدة بيانات مشتركة مع عزل البيانات عن طريق tenant_id

حزمة التقنيات:
-----------------
• Backend: Laravel (PHP)
• Frontend: Laravel Blade + Bootstrap
• Database: MySQL/PostgreSQL
• JavaScript: jQuery + AJAX
• Modules: nwidart/laravel-modules
• Permissions: spatie/laravel-permission
• Activity Log: spatie/laravel-activitylog
• Payments: Laravel Cashier (Stripe)
